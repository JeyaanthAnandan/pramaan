The rule

The LLM never computes a compliance number. A Decimal engine does: 380 nodes, each tied to a photo region, an official EC file (with its SHA-256) or a stated assumption. No regulatory value is typed by hand.

Verifier spot-check: Pramaan draws the sample a verifier would (every value a person touched, the supplier's data, then the rest by weight). Each one is shown as its crop, so a year of paper becomes a dozen crops checked in minutes.

Each step down is one click: report → formula → inputs → the crop on the original photo, with both readings, who approved it and when.07

§ 3 · Gen AI core · 3 of 3Voice and live vision
Sheet09 / 14

Talk to your report in five languages. Every number it says is checked.

Englishहिंदीਪੰਜਾਬੀதமிழ்Tiếng Việt

  1. Gemini 3.8 Live on Agent Platform answers out loud in 1.1–2.3 s, and the caller can interrupt.

  2. Four tools run in our code: explain_number · open_evidence · search_guidance · open_items. It cannot compute, approve or send.

  3. The server transcribes the agent's own voice and matches every number to the report. A number that isn't in it is flagged, and the agent corrects itself aloud.

  4. Credentials stay on Cloud Run: 16 kHz audio over a WebSocket, a 5-minute cap, no recording kept.
